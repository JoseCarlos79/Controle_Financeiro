MEU CONTROLE FINANCEIRO - VERSAO COM SINCRONIZACAO (GitHub Pages + Firebase)

COMO FUNCIONA
  - O app fica no GitHub Pages (site publico, mas SEM nenhum dado seu).
  - Seus dados ficam no Firebase (Firestore), protegidos por login Google e por regras
    que so liberam a leitura e a escrita para o SEU e-mail.
  - Celular e computador mostram os mesmos dados.
  - Custo: plano Spark do Firebase, que nao pede cartao. Este app usa muito menos que a cota gratuita.

ARQUIVOS (envie todos para a raiz do repositorio do GitHub)
  index.html, firebase-config.js, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

PASSO A PASSO
  1. FIREBASE - criar projeto
     console.firebase.google.com > Adicionar projeto > de um nome > pode desativar o Google Analytics > Criar.
  2. LOGIN GOOGLE
     Build > Authentication > Comecar > aba "Sign-in method" > Google > Ativar > escolha seu e-mail de suporte > Salvar.
  3. BANCO DE DADOS
     Build > Firestore Database > Criar banco de dados > edicao Standard > local southamerica-east1 (Sao Paulo)
     > iniciar em modo de producao > Criar.
     Depois abra a aba "Regras", apague o conteudo, cole as regras abaixo (troque SEU-EMAIL@gmail.com pelo seu e-mail
     do Google) e clique em Publicar:

       rules_version = '2';
       service cloud.firestore {
         match /databases/{database}/documents {
           match /users/{uid}/{document=**} {
             allow read, write: if request.auth != null
               && request.auth.uid == uid
               && request.auth.token.email == "SEU-EMAIL@gmail.com";
           }
         }
       }

  4. REGISTRAR O APP WEB
     Engrenagem > Configuracoes do projeto > "Seus apps" > icone </> (Web) > de um apelido > Registrar app
     (NAO precisa marcar o Firebase Hosting). Copie os valores apiKey, authDomain, projectId e appId do bloco
     firebaseConfig e cole no arquivo firebase-config.js, entre as aspas.
  5. AUTORIZAR O ENDERECO DO GITHUB
     Authentication > Settings (Configuracoes) > Authorized domains > Add domain > SEU-USUARIO.github.io
  6. GITHUB
     No repositorio, Add file > Upload files > envie os 7 arquivos (substitui os antigos) > Commit changes.
     Settings > Pages > Deploy from a branch > main > / (root) > Save (se ainda nao fez).
  7. ENTRAR
     Abra https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/ > toque em "Entrar com Google".
     Use o MESMO e-mail das regras. Faça o mesmo no outro aparelho.
  8. TRAZER OS DADOS (uma vez so)
     Aba Contas > cole o codigo de dados > Carregar codigo. Ele sobe para o Firebase e aparece nos dois aparelhos.
  9. INSTALAR
     Chrome > menu > Instalar app (celular) ou icone de instalar na barra de enderecos (computador).

SEGURANCA
  - Os valores do firebase-config.js nao sao segredo; quem protege os dados sao as regras do passo 3.
  - NAO envie para o GitHub o arquivo com seus dados (meus-dados-NAO-PUBLICAR.txt) nem codigos de backup.

SE DER ERRO, o aviso no topo do app mostra o motivo. Os mais comuns:
  - "endereco nao autorizado": refaca o passo 5.
  - "regras do Firestore negaram o acesso": confira o e-mail nas regras (passo 3) e se clicou em Publicar.
  - "nao configurada": o firebase-config.js ainda esta vazio (passo 4).
